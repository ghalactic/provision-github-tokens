# Record architecture decisions

Architectural decisions on this project are recorded as Architecture Decision
Records (as described by [Michael Nygard][nygard]) so that future contributors
can understand the reasoning behind them. Each ADR is a short note capturing a
decision and the trade-offs that led to it — closer to a commit message with
rationale than a design document.

[nygard]:
  https://www.cognitect.com/blog/2011/11/15/documenting-architecture-decisions
